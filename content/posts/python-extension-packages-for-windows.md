> **Update (2026):** Phần lớn các package ngày nay đã có sẵn wheel dựng sẵn cho Windows (kể cả 64-bit) trên PyPI, nên chỉ cần `pip install <tên-package>`. Trang bên dưới là nguồn cũ và có thể không còn được cập nhật.

There is a collection of some unofficial packages and modules for Python on Windows. Most of them are available in x64 builds.

<https://www.lfd.uci.edu/~gohlke/pythonlibs/>
